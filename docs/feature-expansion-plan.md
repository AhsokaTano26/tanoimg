# 图床功能扩展实施计划

本计划对应用户选定的 1–18、20、21、23、25–27、30–35、37、39 项，以及图库分页和 API 标签上传。每个阶段单独验证并提交。实施过程中保持 EasyImg 迁移后的 `id`、`uuid`、`filename` 和 `/i/<filename>` 不变。

## 兼容性约束

- 现有图片的非公开状态映射为 `unlisted`：不进入公共图库，但原直链继续有效。新上传图片可选择 `private`，原图和缩略图都需登录或有效分享授权。
- `uploaded_by_type` 仅表示上传来源，不再承担访问控制职责。
- 原图替换保留原 ID、UUID、文件名、扩展名和 URL。格式不兼容时拒绝替换；旧版默认保留最近 3 版，管理员可设置。
- 图片处理、校验、导出、任务扫描均使用流式 I/O 和有界队列；避免将整张图片或 ZIP 放入内存。
- 旧 EasyImg API Key 在迁移期间仍能使用；新密钥只显示一次，数据库只保存摘要。

## 阶段与验收

1. **图库基础（1、2、4、5、9，分页，API 标签）**：新增独立可见性、标签、相册和描述元数据；支持筛选、搜索、批量更改可见性；流式计算内容摘要并显示准确重复提示；图库可跳首页、末页、指定页和切换每页数量。兼容性测试覆盖旧直链和新私有访问。
2. **文件生命周期（3、6、11、16、21、30）**：有界生成并缓存缩略图、可选元数据清理、相同 URL 原图替换与回滚、可配置回收站保留期、资源感知处理队列，以及只报告异常的完整性检查。旧版保留数默认 3。
3. **分享与内容（7、8、10、12–15）**：单图详情、合集分享、裁剪旋转遮盖、嵌入模板、流式 ZIP、举报和匿名上传凭据及自助删除。真正私有图片的裸直链不能由分享功能变为公开。
4. **上传可靠性（17、18、20、23、25–27）**：幂等键、持久化批次结果对账、公平队列、可续传单文件上传、可选 Turnstile、按日数量与流量配额及每密钥上传策略。失败上传不能计入成功额度。
5. **运维与安全（31–35、37、39）**：任务中心、审计日志、深度健康与告警、传输量统计、维护模式、API Key 权限/到期/摘要迁移，以及与真实接口同步的 OpenAPI 文档。

每阶段先写针对行为和兼容性的测试，再实现和运行 Go、前端测试与生产构建。阶段间逐步提交，最后核对全部编号及部署文档。

## 完成记录

上述五个阶段及图库跳页、每页数量、API 上传标签均已接入。后台新增图库管理、分享、相册、传输用量、运行与审计、嵌入模板及相关设置页；公共页面保留图库、上传、详情、相册和分享。浏览器编辑器已在可见 Safari 中验证旋转、另存和原位替换。功能用法与边界见 [新增功能指南](feature-guide.md)，具体接口见 [`openapi.json`](../internal/app/openapi.json)。
