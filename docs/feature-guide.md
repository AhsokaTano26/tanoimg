# 图库扩展功能指南

本页记录图库、上传、分享和运维功能。完整字段、请求与响应以 [OpenAPI 文档](../internal/app/openapi.json) 为准；部署后也可以访问 `/api/openapi.json`。

## 可见性与迁移

| 状态 | 公共图库 | 已知 `/i/` 直链 | 适用场景 |
| --- | --- | --- | --- |
| 公开 `public` | 显示 | 可访问 | 对外展示 |
| 不列出 `unlisted` | 不显示 | 可访问 | 需要维持旧外链的图片 |
| 私人 `private` | 不显示 | 需管理员会话或有效分享授权 | 新的受保护图片 |

EasyImg 迁移来的旧私人图片归为“不列出”，保留原 ID、UUID、文件名和直链。新图片可以选真正的私人模式；将旧图手动改为私人会影响原直链使用者。图库可按关键词、格式、标签和可见性筛选，按时间、名称或大小排序；支持首尾页、指定页和每页数量。管理员可批量改可见性或加入相册。

图片详情显示替代文字、作者、许可、标签和文件信息。上传时可填写标签；API 文件和 URL 上传都可传 `tags`。服务端流式计算 MD5，可用于准确提示已有的相同内容。管理员还可以导出图片及元数据，查看完整性检查报告。

## 图片生命周期

- 缩略图按需生成并缓存，常用 JPEG、PNG、GIF/APNG 可生成 320 像素缩略图；原图与缩略图遵守同一访问权限。
- 管理员可原位替换图片，保持 ID、UUID、文件名和 `/i/` URL；替换文件须与原格式相同。旧版默认保留最近 3 版，可在“存储清理”调整到 0–10 版并回滚。
- 可选移除新上传 JPEG 的 EXIF、XMP、IPTC 与注释。非默认 EXIF 旋转方向会被拒绝，以免清除方向信息后显示错误。
- 删除先进入回收站，可以恢复；可配置自动清理保留期。定期检查仅报告缺失或异常文件，不会自动改写原图。

同一路径原位替换采用修订号 ETag 和重新验证缓存策略。若 CDN 自行长期缓存，替换后需清除 CDN 上对应原图和缩略图 URL。

## 分享与内容管理

管理员可建立公开或私人相册，并排序相册里的图片。单图或多图可以建立有期限或访问限制的分享链接；分享令牌只显示给需要访问的人，撤销后链接立即失效。私人图片的裸直链仍需鉴权，分享页使用自己的授权访问路径。合集下载使用流式 ZIP。

图片页提供直链、HTML、Markdown、BBCode 等嵌入代码，管理员可配置嵌入模板。访客可举报图片，管理员在“运行与审计”处理举报。匿名上传成功后会显示一次性自删凭据；保存图片 ID 和凭据后，可在公共图库的上传框内自助删除。凭据不会保存在浏览器本地存储，响应丢失后也无法找回。

## 大批量上传与防护

网页管理员队列最多 4 路并发。普通文件和 URL 请求附带每项独立 `Idempotency-Key`；网络异常时先调用 `POST /api/uploads/reconcile`，只有确认未知后才使用原键重试。管理员选择 16 MiB 及以上文件时，浏览器分片计算 SHA-256，再通过分块会话上传；失败后查询服务器偏移继续。会话保留 24 小时。API 客户端也可以直接使用 `/api/upload/resumable` 系列接口。

公共上传可选 Cloudflare Turnstile，同时保留 IP 速率限制和自动封禁。可配置每 IP 每日张数及字节数；API Key 也可以设定独立每日配额、权限、到期时间及上传策略。成功上传才计入配额。密钥创建时只显示一次原文，数据库保存摘要；迁移的 EasyImg 密钥仍可使用。

## 运维

“运行与审计”提供后台任务、审核与通知队列、健康和告警、审计记录、举报、完整性检查及维护模式。`/readyz` 会检查数据库和数据卷剩余空间，适合 Zeabur 或反向代理健康检查。维护模式阻止匿名写入，管理员仍可管理站点。

“传输用量”统计经应用返回的原图、缩略图及分享文件请求，可以设置每 GiB 单价估算流出费用。它是应用层估算，不包含 CDN 在边缘直接响应的流量，也不能替代云服务商账单。OpenAPI 3.1 JSON 位于 `/api/openapi.json`，后台“API 文档”有可直接复制的示例。
