# 访客页与后台拆分验收（2026-09-24）

## 实现

- 访客：图片首页、公共上传、header 登录；不挂载后台导航与管理表单。
- 后台：登录后进入 /admin/gallery；上传、回收站、统计、API 和设置使用受保护的子路由。
- Vue Router 的 RouterLink、RouterView、导航守卫和页面生命周期负责导航与清理。旧链接保留重定向。
- Go 页面入口校验管理员会话；API 保持原有权限检查。
- 前端使用本地构建资源与 Lucide 图标，运行时不需要 Node.js。
- 公共图库请求 scope=public，管理员浏览公共页面也遵循公开展示配置。
- 退出登录返回公共首页；未登录打开后台地址转至登录，登录后返回原目标。
