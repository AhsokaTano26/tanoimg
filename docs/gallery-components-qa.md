# 图库交互与设置组件改造验证

日期：2026-09-24。使用独立 `/tmp/tanoimg-router-review` 数据目录与 3041 测试服务，不修改生产数据。浏览器为可见 Codex IAB，没有使用无头模式。

## 已实现与核对

- PrimeVue 包装输入框、数字输入、下拉、复选框、滑块、按钮、文件选择、菜单、弹窗、进度条、移动端抽屉；业务页面不直接创建原生控件，不调用 alert/confirm/prompt。
- 图片右键和“更多”菜单：直链、HTML、Markdown、BBCode、全局背景、站点 Logo、可恢复删除。访客的管理菜单禁用，后端写接口仍校验管理员。
- 外观背景和 Logo 可从分页图库选择；模糊滑块支持键盘操作。背景透明度 0.72，内容面板保留可读性。
- 登录上传可选私人／公开；默认私人，4 路有界上传队列。私人仅表示公共图库不可见，直链可访问。
- 公共上传位于图库上方，支持选图、拖放、粘贴、URL；旧 `/upload` 重定向图库上传区。访客队列串行，避免默认禁止同 IP 并发时反复失败。
- 允许格式使用复选框；设置分拆为独立受保护路由；API 文档包含参数、代码高亮、错误码和批量接入说明。
- 公共上传自动封禁支持开关、窗口和次数；SQLite 持久化、并发原子更新、管理员解除时重置计数。管理员和 API Key 上传豁免。
- 全站 Vue Router 过渡动画支持减少动态效果偏好。

## 自动验证

- `npm test --prefix frontend`：路由权限、旧路由兼容、安全跳转、分享格式转义、Retry-After、1 万项队列最多 4 并发与取消。
- `go test ./...`：上传可见性、公开图库隔离、公开 URL 格式和 SSRF、自动封禁阈值／窗口／并发／解除、后台页面保护、JS/CSS 嵌入资源 MIME，以及既有兼容性测试。
- `make build`：Vite 分块构建、Go 单二进制打包。
- `git diff --check`；业务源码原生控件与浏览器原生对话框调用扫描。
